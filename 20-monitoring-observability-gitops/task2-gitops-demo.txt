----- A real bug hit and fixed before this run -----

First attempt: the reconciler script died silently after its very first iteration.
Root cause: `kubectl apply -f app/` applies every file in the directory as ONE batch;
on a truly fresh cluster the Deployment (inside the gitops-demo namespace) and the
Namespace itself were submitted together, and the Deployment's creation failed because
the Namespace didn't exist yet at that exact moment within the same batch. The script had
`set -e`, so that failure killed the whole loop instantly -- a genuinely real kubectl
apply ordering gotcha, not something specific to GitOps.
Fix: apply namespace.yaml explicitly first (idempotent on every later loop), then apply
the rest of app/ as before. See gitops-demo/reconciler.sh for the fixed version.
