===== Monitoring & Observability: practical demo =====

----- Monitoring: "is the system healthy?" -- metrics-server + kubectl top -----
pod/mon-demo created
$ kubectl top nodes
NAME     CPU(cores)   CPU(%)   MEMORY(bytes)   MEMORY(%)   
colima   785m         39%      1382Mi          47%         
$ kubectl top pod mon-demo
NAME       CPU(cores)   MEMORY(bytes)   
mon-demo   0m           2Mi             

----- Observability signal 1: Metrics -- numbers over time -----
$ kubectl get --raw "/apis/metrics.k8s.io/v1beta1/pods/default/mon-demo" | python3 -m json.tool
Error from server (NotFound): the server could not find the requested resource
Expecting value: line 1 column 1 (char 0)

----- Observability signal 2: Logs -- discrete events -----
$ kubectl exec mon-demo -- sh -c "for i in 1 2 3; do echo \"[app] handled request \$i\"; done"

[app] handled request 3
