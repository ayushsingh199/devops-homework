----- 1. ClusterIP (default, internal only) -----
$ cat 01-clusterip.yml
apiVersion: v1
kind: Service
metadata:
  name: web-clusterip
spec:
  type: ClusterIP   # default — internal only
  selector:
    app: web-app
  ports:
    - port: 80
      targetPort: 80
service/web-clusterip created
$ kubectl get svc web-clusterip

----- 2. NodePort (reachable on every node at a fixed high port) -----
$ cat 02-nodeport.yml
apiVersion: v1
kind: Service
metadata:
  name: web-nodeport
spec:
  type: NodePort
  selector:
    app: web-app
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
service/web-nodeport created
$ kubectl get svc web-nodeport
NAME           TYPE       CLUSTER-IP     EXTERNAL-IP   PORT(S)        AGE
web-nodeport   NodePort   10.43.62.209   <none>        80:30080/TCP   0s
$ curl -s http://localhost:30080 | grep -i title      # colima forwards the node IP to the Mac

----- 3. LoadBalancer (fixed port conflict -- see 03-loadbalancer.yml comment) -----
$ cat 03-loadbalancer.yml
apiVersion: v1
kind: Service
metadata:
  name: web-loadbalancer
spec:
  type: LoadBalancer
  selector:
    app: web-app
  ports:
    - port: 8888       # a different external port -- port 80 is already claimed by
      targetPort: 80    # the ingress-nginx-controller's own LoadBalancer service on this
                         # single-node cluster (servicelb binds one hostPort per LB service)
service/web-loadbalancer created
$ kubectl get pods -n kube-system -l svccontroller.k3s.cattle.io/svcname=web-loadbalancer   # servicelb helper pod

svclb-web-loadbalancer-dab4a472-24lkv           1/1     Running   0          8s
$ kubectl get svc web-loadbalancer

web-loadbalancer   LoadBalancer   10.43.227.160   192.168.5.1   8888:31034/TCP   8s

(k3s's built-in servicelb assigned the node's own IP as the external IP -- on a real cloud
 provider [AWS/GCP/Azure], the same "type: LoadBalancer" spec would instead provision a real
 cloud load balancer with the cloud's own public/external IP -- Kubernetes stays identical either way)

----- 4. ExternalName (pure DNS CNAME alias, no selector, no pods, no proxying) -----

----- 5. Headless Service (clusterIP: None -- DNS returns every pod IP directly) -----
$ cat 05-headless.yml
apiVersion: v1
kind: Service
metadata:
  name: web-headless
spec:
  clusterIP: None   # <-- headless
  selector:
    app: web-app
  ports:
    - port: 80
      targetPort: 80
service/web-headless created
$ kubectl get svc web-headless      # note CLUSTER-IP column: "None"
